# 📋 ВЫЖИМКА ПРОЕКТА PL-1

**Дата обновления:** 18.09.2026 (вечер)

## 🎯 Проект
PL-1 — приложение для общения логистов с водителями в контексте доставки товаров.

**Стек:** FastAPI + SQLAlchemy (async) + PostgreSQL + Redis + Alembic + SQLAdmin + MAX Bot API + Docker

**Репозиторий:** github.com/Softinapro/PL-1.git (приватный)

## 📚 ТЕРМИНОЛОГИЯ
- ДеньОтгрузки — дата (обычно завтра). Контекст всей работы.
- Trip — задание водителю на ДеньОтгрузки (водитель + дата)
- Route = Рейс — маршрут (1 маршрут = 1 документ 1С «Рейс»)
- Point — торговая точка (магазин)
- Логист — работает в 1С, в приложении не создаётся
- Водитель — получает задание в MAX, подтверждает/отклоняет

## 🔄 БИЗНЕС-ЛОГИКА

### Основной поток
1. 1С создаёт заказы на доставку в торговые точки
2. Логист формирует маршруты (по географии + весу)
3. Импорт в приложение через POST /import/trips (с X-API-Key)
4. Trip создаётся со статусом PENDING
5. Водитель получает уведомление в MAX
6. Водитель: Подтвердить всё / Отказаться
7. Логист видит отказы в дашборде (real-time, позже)
8. Логист пересобирает → затирает старым → новое уведомление
9. Итерация до финала: все подтверждены или водитель исключён
10. 1С забирает результаты (по таймеру)

### Ключевые правила
- Дата отгрузки всегда уникальная (в системе активна одна дата)
- Точка в один день — в одном маршруте, в разные дни — в разных
- Вес приходит по каждой точке из 1С
- Новый импорт ЗАТИРАЕТ старый Trip (удаление + создание нового)
- Отказы водителя сохраняются отдельно (Trip удаляется, отказы — нет)
- Водитель может откатить отказ — логист видит сразу

## 📊 МОДЕЛИ БД

### User
- phone (String(20), unique, not null, index)
- full_name (String(100), not null)
- code (String(10), unique, nullable, index) — код из 1С (физлица)
- role (Enum: admin/logist/driver)
- is_active (Boolean, default True)
- is_archived (Boolean, default False)
- max_user_id (String(100), unique, nullable)

### DriverProfile
- user_id (FK), max_user_id (String(100), unique, nullable), is_verified

### Trip (задание на ДеньОтгрузки)
- driver_id (FK users.id, not null, index)
- logist_id (FK users.id, nullable, index) — всегда None (логисты не создаются)
- logist_code (String(10), nullable, index) — код логиста из 1С
- date (Date, not null, index)
- status (Enum: PENDING/SENT/CONFIRMED/PARTIAL/REJECTED)
- sent_at (DateTime, nullable)
- info (String(300), nullable)

### Route (маршрут = рейс)
- trip_id (FK trips.id, not null, index)
- order_number (Integer, not null)
- name (String(255), nullable)
- status (Enum: PENDING/CONFIRMED/REJECTED)
- rejection_reason (Text, nullable)
- address_start (String(255), not null)
- address_end (String(255), not null)

### Point (торговая точка)
- route_id (FK routes.id, not null, index)
- code (String(10), not null, index) — код точки из 1С
- date (Date, not null, index) — дата отгрузки
- order_number (Integer, not null)
- address (String(255), not null)
- weight (Numeric(10, 3), nullable) — вес, кг
- status (Enum: PENDING/CONFIRMED/REJECTED)
- rejection_reason (Text, nullable)
- UniqueConstraint (code, date) — uq_point_code_date

### BaseModel
- id, created_at, updated_at
