🌐 Туннель CloudPub

1. Запустить туннель

~/clo publish http host.docker.internal:8000
~/clo publish http host.docker.internal:8000
# Новый адрес появится в выводе, например: https://winsomely-reassuring-hen.cloudpub.ru

2. Проверить, что туннель работает

curl https://<ТВОЙ_АДРЕС>.cloudpub.ru/health
curl https://<ТВОЙ_АДРЕС>.cloudpub.ru/health
{"status":"ok","service":"logistics-api"}

3. Посмотреть активные туннели

~/clo ls
~/clo ls

4. Остановить туннель

~/clo stop && ~/clo clean
~/clo stop && ~/clo clean
Подсказка Если туннель не работает через localhost, используй IP-адрес WSL:
hostname -I | awk '{print $1}' → затем ~/clo publish http <IP>:8000

🆘 Частые ошибки и решения

Ошибка Решение
Connection reset by peer Смотреть логи: docker compose logs backend --tail 50
No module named 'app' Пересобрать контейнер: docker compose up -d --build
503 Service Unavailable Перезапустить туннель: ~/clo stop && ~/clo clean && ~/clo publish http host.docker.internal:8000
Could not resolve host: github.com Перезапустить WSL: в PowerShell выполнить wsl --shutdown
service "backend" is not running Запустить контейнеры: docker compose up -d
ModuleNotFoundError: No module named 'maxo' Удалить maxo из requirements.txt и пересобрать
invalid input value for enum userrole Использовать значения в верхнем регистре: ADMIN, LOGIST, DRIVER
No config file 'alembic.ini' found Инициализировать Alembic: alembic init alembic внутри контейнера
